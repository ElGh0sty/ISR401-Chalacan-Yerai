# TA-IND-01: Trabajo individual - IEEE 29148 y tipos de requisitos

Repositorio correspondiente al trabajo autónomo individual de la asignatura **Ingeniería de Requerimientos (ISR-401)** de la Carrera de Software en la Universidad Técnica Estatal de Quevedo (UTEQ).

## Estructura del Repositorio
- `TA-IND-01/main.tex`: Archivo principal en LaTeX con el informe completo (resumen, glosario, requisitos, autoevaluación y reflexión).
- `TA-IND-01/referencias.bib`: Archivo de bibliografía en formato IEEE.
- `TA-IND-01/figuras/`: Carpeta que contiene las capturas de pantalla propias del sistema analizado (Mercado Libre):
  - `cap1.jpeg` (Filtros de búsqueda)
  - `cap2.jpeg` (Detalle de producto y stock)
  - `cap3.jpeg` (Pantalla de pago y checkout)
- `TA-IND-01/main.pdf`: Documento PDF compilado final.

## Instrucciones para Compilar el Documento LaTeX

El documento está optimizado para compilarse utilizando el motor **LuaLaTeX**. A continuación se detallan la ejecución:

### Overleaf 
1. Sube o clona este repositorio en un proyecto de **Overleaf**.
2. Dirígete a la configuración del proyecto (botón **Menu** en la esquina superior izquierda).
3. Cambia el campo **Compiler** a **LuaLaTeX**.
4. **Gestión de imágenes:** Asegúrate de ingresar los archivos de imagen en Overleaf y sube allí tus tres capturas con los nombres exactos:
   - `captura1.jpeg`
   - `captura2.jpeg`
   - `captura3.jpeg`
5. Haz clic en **Recompile** para generar el documento PDF final sin errores.
